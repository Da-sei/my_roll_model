# 実装計画

- [x] 1. バックエンドにキャラクター更新 API を追加する
- [x] 1.1 (P) PUT エンドポイントでキャラクター情報を更新できるようにする
  - リクエストボディから名前と説明を受け取り、指定 ID のレコードを更新する
  - 名前が空の場合は 400 エラーを返す
  - ID のパースに失敗した場合は 400 エラーを返す
  - 対象レコードが存在しない場合は 404 エラーを返す
  - DB エラー時は 500 エラーを返す
  - 既存の POST / DELETE ハンドラと同一のコード構成パターンに従う
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5_

- [x] 2. フロントエンドの API クライアントに更新・削除関数を追加する
- [x] 2.1 (P) キャラクター更新用の API 呼び出し関数を追加する
  - 指定 ID のキャラクター情報を PUT リクエストで送信する機能を実装する
  - 更新リクエスト用の型定義（名前: 必須、説明: 任意）を追加する
  - 既存の登録関数と同じエラーハンドリングパターンを適用する
  - _Requirements: 6.1, 6.3, 6.4_

- [x] 2.2 (P) キャラクター削除用の API 呼び出し関数を追加する
  - 指定 ID のキャラクターを DELETE リクエストで削除する機能を実装する
  - 既存の登録関数と同じエラーハンドリングパターンを適用する
  - _Requirements: 6.2, 6.3_

- [x] 3. キャラクターカードを独立コンポーネントに分離する
- [x] 3.1 個別のキャラクター表示カードコンポーネントを作成する
  - 名前・説明の表示に加え、「編集」と「削除」の操作ボタンを設置する
  - 編集モードと削除確認モードの切り替え状態を管理する
  - 既存のカードスタイルを維持する
  - _Requirements: 2.1, 4.1_

- [x] 4. インライン編集フォームを実装する
- [x] 4.1 カード内で直接キャラクター情報を編集できるフォームを作成する
  - 編集開始時にキャラクターの現在の名前・説明を入力フィールドに設定する
  - 名前必須・255文字以内のバリデーションを適用する
  - 「保存」ボタンと「キャンセル」ボタンを表示する
  - キャンセル時はフォームを閉じて元のカード表示に戻す
  - _Requirements: 2.2, 2.3, 2.4, 2.5_

- [x] 4.2 編集フォームから更新 API を呼び出して保存する
  - 有効な入力内容で保存ボタンを押した際に更新 API にリクエストを送信する
  - 成功時はフォームを閉じてカード表示を更新し、成功メッセージを表示する
  - エラー時はフォームを閉じずにエラーメッセージを表示する
  - API 送信中は保存ボタンをローディング状態にし、二重送信を防止する
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5_

- [x] 5. 削除確認ダイアログを実装する
- [x] 5.1 削除前の確認 UI をカード内オーバーレイとして作成する
  - キャラクター名を含む削除確認メッセージを表示する
  - 「削除する」ボタン（警告色）と「キャンセル」ボタンを配置する
  - キャンセル時はダイアログを閉じて何も変更しない
  - _Requirements: 4.2, 4.3, 4.4_

- [x] 5.2 削除確認後に削除 API を呼び出して実行する
  - 「削除する」ボタン押下時に削除 API にリクエストを送信する
  - 成功時は一覧から該当カードを除外し、成功メッセージを表示する
  - エラー時はエラーメッセージを表示する
  - API 送信中は削除ボタンをローディング状態にし、二重送信を防止する
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5_

- [x] 6. 一覧コンポーネントとページを統合する
- [x] 6.1 一覧コンポーネントをカードコンポーネントを使用する形に更新する
  - インラインのカード JSX を新しいカードコンポーネントに置き換える
  - 編集・削除成功時にリフレッシュをトリガーするコールバックを接続する
  - _Requirements: 2.1, 4.1_

- [x] 6.2 ページコンポーネントにリフレッシュコールバックを接続する
  - 一覧コンポーネントに編集・削除用のリフレッシュコールバックを渡す
  - 新規登録と同じリフレッシュ機構を共用する
  - _Requirements: 3.2, 5.2_
